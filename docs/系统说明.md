# 系统说明

## 1. 项目定位

本系统是课程大作业第一阶段的简化在线问卷平台，目标不是覆盖问卷星的全部功能，而是完整实现“问卷创建—题目配置—链接分发—登录填写—条件跳转—提交保存—统计查看”的闭环，并重点展示 MongoDB 文档建模与后端业务逻辑能力。

## 2. 用户角色

| 角色 | 能力 |
| --- | --- |
| 未登录访客 | 注册、登录；不能创建或填写问卷 |
| 登录用户 | 创建问卷、管理自己的问卷、发布或关闭问卷、查看自己的统计结果 |
| 问卷创建者 | 查看自己问卷的题目、公开链接、提交情况、整卷或单题统计 |
| 问卷填写者 | 通过公开链接进入，登录后逐题填写；可匿名提交或被记录账号 |

权限边界：问卷管理接口都会校验 owner_id；其他账号直接访问管理页会返回 404，避免泄露问卷是否存在。

## 3. 功能模块

### 3.1 账号模块

- 注册：用户名为 3-30 位中文、字母、数字或下划线，用户名统一小写后保证唯一。
- 密码：至少 6 位，使用 Werkzeug 默认 scrypt 哈希保存，不保存明文。
- 会话：登录后 Flask 签名 Cookie 保存用户 ID，退出时清空会话。
- 登录保护：问卷管理、公开链接进入、答题操作均要求登录。

### 3.2 问卷管理模块

- 新建草稿：填写标题、说明、是否允许匿名、是否允许重复填写。
- 设置：修改标题、说明、截止时间；草稿阶段还可修改匿名和重复填写开关。
- 发布：至少有一道题且截止时间有效时才能发布；发布后生成公开链接。
- 关闭：创建者可主动关闭问卷；达到截止时间后系统自动关闭。
- 公开链接：/survey/公开编号，编号由 secrets 随机生成并建立唯一索引。

### 3.3 题目模块

支持四种输入控件，覆盖需求中的三类题型：

| 题型 | 用途 | 配置 |
| --- | --- | --- |
| single | 单选题 | 至少两个选项、是否必答 |
| multiple | 多选题 | 选项、最少选择数、最多选择数、是否必答 |
| text | 文本填空 | 最少字数、最多字数、是否必答 |
| number | 数字填空 | 最小值、最大值、是否只允许整数、是否必答 |

选项编号由系统自动生成 A、B、C……，跳转规则通过编号引用选项，避免用户修改选项文字后规则失效。

问卷发布后题目结构锁定，防止已有答卷与题目结构冲突；草稿阶段支持添加、删除题目，删除题目时会自动清理指向该题目的跳转规则。

### 3.4 跳转模块

每道题可以有多条跳转规则，规则包含“条件”和“目标题目”。目标可以是后续任意题目，也可以是“结束问卷”。规则按数组顺序匹配，命中第一条即生效；未命中时默认进入下一题。

支持的条件：

| 题型 | 条件 |
| --- | --- |
| 单选 | 等于、不等于某个选项 |
| 多选 | 包含任意、包含全部、不包含某些选项 |
| 数字 | 等于、不等于、大于、大于等于、小于、小于等于、介于区间 |
| 文本 | 包含、等于、不等于 |

只允许跳向后续题目，从结构上避免死循环；需要提前结束时选择“结束问卷”。

### 3.5 填写模块

- 填写者登录后打开公开链接，阅读说明并开始答卷。
- 系统为每次答卷生成独立 response 文档和随机访问令牌。
- 每道题单独显示，提交后由服务端校验并计算下一题。
- 每次有效作答立即写入 MongoDB，刷新或中途退出不会丢失前面的答案。
- 全部完成或命中 END 规则后，答卷状态变为 submitted，并记录提交时间。
- 同一账号的多次填写通过 respondent_key 区分；当 allow_multiple=false 时禁止第二次提交。

### 3.6 统计模块

创建者可以查看：

- 问卷总提交数。
- 每道题的回答人数。
- 单选每个选项被选择的人数和百分比。
- 多选每个选项被选择的次数和百分比。
- 文本题全部回答内容。
- 数字题全部值、平均值、最小值、最大值。
- 通过“全部题目”和 Q1/Q2… 链接在整卷与单题视图之间切换。
- 通过 /api/surveys/问卷ID/stats 获取 JSON 统计结果。

统计只计算 status=submitted 的答卷；填写中的草稿不进入统计。

## 4. 典型使用流程

1. 用户注册并登录。
2. 创建问卷草稿，设置匿名与重复填写策略。
3. 依次添加单选、多选、文本、数字题目。
4. 为题目配置跳转规则，例如“第 1 题选 A 则跳到第 3 题”。
5. 设置截止时间并发布。
6. 将 /survey/公开编号 链接发给填写者。
7. 填写者登录后逐题作答，服务端校验并执行跳转。
8. 创建者在统计页查看实时汇总结果。

## 5. 页面清单

| 路径 | 页面 |
| --- | --- |
| /register | 注册 |
| /login | 登录 |
| /dashboard | 我的问卷 |
| /surveys/new | 新建问卷 |
| /surveys/ID | 问卷管理、题目与跳转配置 |
| /surveys/ID/stats | 统计结果 |
| /survey/公开编号 | 问卷说明与开始填写 |
| /attempt/ID | 单题填写页 |
| /attempt/ID/complete | 提交成功页 |
| /health | 数据库健康检查 |

## 6. 第一阶段范围说明

本阶段完成了初始需求中的全部核心能力。为保持数据一致性，题目结构在发布后锁定；若后续需要在线修改已发布题目，应在第二阶段引入题目版本或答卷题目快照策略，而不是直接覆盖题目文档。该限制已作为第二阶段扩展点记录在项目报告中。
